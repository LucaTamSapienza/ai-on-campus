# Font del PDF del piano di studio

Usati solo da `components/study/plan-document-pdf.tsx`, che genera il PDF nel browser.
Tutti con licenza SIL Open Font License 1.1, scaricati da Fontsource (`cdn.jsdelivr.net/fontsource`, versione 5.3.0).

| File | Font | Perché |
|---|---|---|
| `jakarta-400.ttf`, `jakarta-600.ttf`, `jakarta-700.ttf` | Plus Jakarta Sans, sottoinsieme latin | il font del design system |
| `noto-greek-400.ttf`, `noto-greek-700.ttf` | Noto Sans, sottoinsieme greek | lettere greche nei nomi dei concetti (ε, π, γ) |
| `noto-math-latin-400.ttf` | Noto Sans Math | simboli matematici (ℝ, ≤, →, ∑) |
